## 💻 Tech Stack
- **Frontend Core:** React 18, Vite, Tailwind CSS
- **3D Graphics:** Three.js (WebGL interactive particle universe, holographic core, dynamic satellite orbit raycasting)
- **Icons & Visuals:** Lucide React, Canvas Confetti
- **Audio:** Web Audio API synthesized tactile feedback

---

## ✨ Features
1. **Interactive 3D Hero Scene:** Rotating holographic wireframe core, 1,800+ undulating cosmic data particles, and orbiting satellite tech nodes.
2. **AWS Serverless Pipeline Simulator:** Step-by-step interactive demonstration of media upload to S3, AWS Lambda event trigger, image optimization, and CloudFront edge delivery.
3. **Finance Analytics Platform:** Interactive finance dashboard with expense categorization and an AI advisory engine.
4. **Blood Bank & Donation Management:** Real-time database CRUD inventory simulation and donor register.
5. **Interactive Developer CLI Terminal:** Retro-futuristic bash terminal supporting commands (`help`, `bio`, `skills`, `projects`, `certs`, `contact`, `matrix`, `resume`).
6. **Academic & Certifications Showcase:** MAKAUT BCA Data Science (9.04 CGPA), 12th (71.6%), 10th (93%), and verified industry credentials.

## 🛠️ Local Development
```bash
# Clone the repository
git clone https://github.com/moumitadeb-23/moumita-portfolio.git

# Navigate to project
cd moumita-portfolio

# Install dependencies
npm install

# Start local server
npm run dev
```
